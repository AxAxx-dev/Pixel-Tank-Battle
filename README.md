# Pixel Tank Battle

A pixel-style tank battle game built with Electron.

## About

Pixel Tank Battle is a pixel-art tank battle game built with Electron, available for Windows and Android.

## Download

请访问 发布](https://github.com/AxAxx-dev/Pixel-Tank-Battle/releases) 页面并选择您需要的版本。

每个版本都提供以下三个文件：

| 文件类型 | 平台 | 描述 |
| --- | --- | --- |
| `Pixel_Tank_Battle_Setup_3.3.8.EXE` | Windows | 安装程序，运行设置向导 |
| `PixelTankBattle_3.3.8-Windows.zip` | Windows | 便携版，解压后运行 |
| `PixelTankBattle_3.3.0-Android.zip` | Android | Android 包 

> `<version>` 根据版本而异。请参阅发布页面上的实际文件名。旧版本也可在那里找到。

##需求

- **Windows**: Windows 10 或更高版本（64位）
- **Android**: Android 8.0 或更高版本

## 备注

- 本软件完全免费。
- Windows 安装程序未进行代码签名。如果它被 360 等安全软件标记，这是未签名程序常见的误报。请将其添加到信任列表中，或在安装前暂时禁用安全软件。
便携版和安装版在功能上完全相同；根据需要选择其中任意一个。

##反馈

如果您遇到任何错误或有建议，请在 [Issues](https://github.com/AxAxx-dev/Pixel-Tank-Battle/issues)中提交问题。

# 像素坦克大战（中文）

一款基于 Electron 开发的像素坦克对战游戏。

## 关于

Pixel Tank Battle 是一款像素风格的坦克对战游戏，使用 Electron 构建，支持 Windows 与 Android 平台。

## 下载

请前往 [Releases](https://github.com/AxAxx-dev/Pixel-Tank-Battle/releases) 页面，选择需要的版本下载。

每个版本均提供以下三类文件：

| 文件类型 | 平台 | 说明 |
| --- | --- | --- |
| `Pixel_Tank_Battle_Setup_3.3.8.EXE` | Windows | 安装版，运行安装向导完成安装 |
| `PixelTankBattle_3.3.8-Windows.zip` | Windows | 免安装版，解压后直接运行 |
| `PixelTankBattle_3.3.0-Android.zip` | Android | 安卓版安装包 |

> 文件名中的 `<版本号>` 随版本变化，请以 Releases 页面实际文件名为准。历史版本也可在同一页面找到。

## 系统要求

- **Windows**：Windows 10 及以上（64 位）
- **Android**：Android 8.0 及以上

## 说明

- 本软件完全免费。
